## 4. How to Edit & Approve Products

### Method A: Direct File Editing (Admin-Friendly JSON)
1. Open `catalog/products.catalog.json`.
2. Edit `name`, `description`, `price`, and `sizes`.
3. Change `"status": "pending_approval"` to `"status": "approved"`.
4. Run `node scripts/generate-catalog.mjs` to re-sync.

### Method B: Interactive Visual Web Preview
1. Open [http://localhost:5173/catalog-preview](http://localhost:5173/catalog-preview) in your browser.
2. Inspect photo angles, edit prices and names directly in the dashboard.
3. Click **"APPROVE FOR STORE"**.
